JupyterLab (the lab runtime)

The core always-on service. JupyterLab serves the student notebooks at /lab and, through --ServerApp.extra_static_paths (set in workspace/entrypoint.sh), the static SKILL, foyer, and browser-course pages at /lab/static/. This directory holds the config baked into the lab image: the shell bashrc and the JupyterLab overrides.json.

One server, two roles. The same JupyterLab process is both the notebook kernel host and the static file server for the whole bundle. The static search path (/sandbox/dli then /sandbox/dli/web) is what lets /lab/static/<path>/SKILL.html resolve. Change that path and the foyer + every SKILL link move with it.
