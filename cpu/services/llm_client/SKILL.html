llm_client

The OpenAI-compatible inference gateway. Every course in the bundle routes its model calls through llm_client:9000. It speaks one OpenAI-shaped API and fans each request out to the right upstream: NVIDIA Inference, OpenAI, or AWS Bedrock Converse, chosen by the model id.

Sole keyholder. llm_client is the only service that holds upstream provider keys: NVIDIA_API_KEY, OPENAI_API_KEY, and AWS_BEARER_TOKEN_BEDROCK. No notebook, browser page, or sibling service ever sees a raw key. Keys are set at runtime through POST /admin/set-key, which infers the provider from the key prefix (nvapi- to NVIDIA, sk- to OpenAI, anything else to Bedrock) and re-runs model discovery with no container restart.

Agent / automation notes

The skill-meta tests array is the machine-readable contract; the rendered list is its executable form. A green run means the catalog answers, a chat completion comes back with content, and embeddings return a non-empty vector through the /lab/svc/llm/ browser route.
