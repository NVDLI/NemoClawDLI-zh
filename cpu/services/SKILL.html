The always-on docker stack the course calls into. Each service carries its own SKILL.html that documents its interface and ships unit tests for it; this page links them and checks the stack is up. Prose per service is in the matching 00_*.md; the cross-service map is 00_service_map.md, and a one-shot stack-health walkthrough is 00_services_check.md.

Where tests live. Interface tests belong to the service that owns the interface, not to its consumers. OpenShell tests are in openclaw/SKILL.html and sandbox_admin/SKILL.html.
