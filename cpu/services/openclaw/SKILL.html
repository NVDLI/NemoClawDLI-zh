OpenClaw / OpenShell

The file-as-context agent runtime, running inside a kernel-contained sandbox. The gateway (openclaw:8995, also openshell:8995) speaks an OpenAI-compatible API. The sandbox-admin control plane (sandbox-admin:8099) manages policy, cron, and a bounded read-only exec console. OpenShell containment is netns + Landlock + seccomp + an OPA-evaluated CONNECT proxy.

Test scope. This service skill owns the executable tests for the OpenClaw gateway, the OpenShell sandbox, and the bounded console. The openshell course (a sibling) teaches the same surfaces, but its SKILL tests course self-consistency, not these live interfaces. Interfaces are tested where the interface lives.
