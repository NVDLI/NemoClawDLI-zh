Homethe bundle toolchain

scripts/translate/ · language branches

A translation is the same course in another language: a translate-<lang> branch that overlays the source, translating the reader-facing prose under web/ and carrying code, assets, and every skill-meta contract verbatim. This folder is the toolchain that keeps that overlay in step with the source. Open the README for the full process, the status tool to see what a sync needs, and walk the guided tour for the contributor loop. Ask the model about any of it with your build.nvidia.com key.

Translation branches skip English prose-style suites but still run structural gates.
