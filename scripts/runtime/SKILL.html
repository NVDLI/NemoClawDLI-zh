Homescripts

scripts/runtime link and browser runtime

Runtime-facing tooling: the single JavaScript link engine, the browser topology viewer, and the thin Python and shell shims that run the same engine in CI.

Browser/container harness commands that need Playwright or lab networking belong here; static gates stay in scripts/validation. Before claiming browser smoke unavailable, run scripts/runtime/browser_env_probe.sh; host Node, Chromium, and Playwright are optional because the test image carries them. If podman compose is unavailable, use the podman-compose-via-python form: python3 -m podman_compose. OpenClaw fallback: if local OpenClaw fails, hangs, or logs EPERM, stop local probing and run the credentialed page harness with the Brev URL plus CF_Authorization in CLAW_CF.

Linkage map

engine.jssingle link engine. Resolves links, builds the page graph, checks reachability, and enforces the release foyer contract. link_projection.pyPython interface. Classification helpers plus thin subprocess shims over engine.js. link_graph.htmltopology viewer. Browser view of the same graph, with an embedded offline snapshot. run_engine.shengine runner. Finds Node and runs engine.js with CI arguments. run_node.shNode resolver. Shared runner for Node-based scripts. browser_env_probe.shbrowser runtime discovery probe. Finds the container engine, checks podman-compose-via-python, and runs smoke before any browser claim. test_page_runtime.jspage runtime smoke test. Exercises browser runtime behavior outside a full lab session. render_check.pyrender check. Headless render helper used by validation and local checks. module_check.pymodule check. Checks module wiring and importability for page scripts.
