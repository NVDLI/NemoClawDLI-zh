Homescripts

scripts/build packaging and deploy helpers

Build and publishing helpers for the static bundle, branch manifests, language manifests, hooks, and edX export.

Some build commands write generated output. Use temporary output paths for checks unless you intend to update release artifacts.

Linkage map

build_pages.shsite assembler. Builds public/ from the client-side course and validation assets. project_docs_explorer.pydocs graph and projection gate. Rejects unlisted or orphaned authored docs, ambiguous generated files, and missing artifact targets. vendor_browser_dependencies.mjsbrowser dependency packager. Generates same-origin bundles, licenses, hashes, and source references from the exact lock. bundle_standalone.pystandalone bundler. Copies and inlines the course into a self-contained web bundle. push_pages.shPages pusher. Pushes the assembled public/ output to the Pages target. publish_edx.pyedX export. Creates the iframe-friendly edX surface. install-hooks.shhook installer. Writes shared dispatchers that run the active worktree's repository gates. build_branch_manifest.pybranch manifest. Lists only production and preview paths published in the current Pages artifact. build_language_manifest.pylanguage manifest. Builds language-branch metadata for translated bundles. package_release.pydeterministic release packager. Builds the versioned archive, manifest, release assets, checksums, and required external-evidence list. build_repository_overview_html.pyhosted slide generator. Projects the shared manifest into a keyboard-navigable HTML deck. build_security_review_package.pySecurity review design composer. Produces one public-safe supporting design from the canonical design and test records. build_repository_overview.mjsPowerPoint generator. Projects the shared manifest into the offline PPTX deck. capture_repository_overview.mjsbrowser evidence capture. Records real course, Studio, and validation surfaces for slide use.
