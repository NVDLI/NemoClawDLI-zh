Homescripts

scripts/build packaging and deploy helpers

Build and publishing helpers for the static bundle, branch manifests, language manifests, hooks, and edX export.

Some build commands write generated output. Use temporary output paths for checks unless you intend to update release artifacts.

Executable checks

Standalone bundlepython3 scripts/build/bundle_standalone.py --src web/nemoclaw --out /tmp/nemoclaw_bundle_check --clean --full
Pages buildbash scripts/build/build_pages.sh
edX exportpython3 scripts/build/publish_edx.py --help

Linkage map

build_pages.shsite assembler. Builds public/ from the client-side course and validation assets. bundle_standalone.pystandalone bundler. Copies and inlines the course into a self-contained web bundle. push_pages.shPages pusher. Pushes the assembled public/ output to the Pages target. publish_edx.pyedX export. Creates the iframe-friendly edX surface. install-hooks.shhook installer. Installs local git hooks that run repo gates. build_branch_manifest.pybranch manifest. Lists only production and preview paths published in the current Pages artifact. build_language_manifest.pylanguage manifest. Builds language-branch metadata for translated bundles.
