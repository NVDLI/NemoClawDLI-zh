The script tree is hierarchical. Implementations live in named subdirectories; root files are compatibility entrypoints for existing commands. Use runtime for the link engine, validation for gates, skills for SKILL contracts, build for packaging, materials for vendored references, figures for runtime diagram checks, edx for export helper pages, dev for local operator helpers, security for iframe proxy audits, and translate for language branches.
