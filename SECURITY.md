# Security policy

Do not report a vulnerability, credential, private URL, customer detail, or exploit path in a
public Issue or Discussion.

For the public GitHub mirror, use
[private vulnerability reporting](https://github.com/NVIDIA/NemoClawDLIOS/security/advisories/new). Include the affected version
or commit, impact, minimal reproduction, and any safe remediation idea. Do not include real
tokens or learner data. If private vulnerability reporting is not enabled, contact the repository
owner through NVIDIA's established private security channel instead of opening a public report.

Course wording, accessibility, source corrections, and non-sensitive runtime defects belong in
the structured Issue templates. Broad questions and ideas belong in Discussions.
