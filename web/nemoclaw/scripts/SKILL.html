Course runtime scripts

These modules support the browser course pages. Page HTML imports scripts/_shared.js; that shared module re-exports page-facing APIs and delegates larger subsystems to smaller siblings. The studio and this SKILL page split the testing job: studio.html is the operator console for running or copying checks, while this beacon is the machine-readable test map agents should parse before changing runtime interfaces. Before claiming browser smoke is unavailable, run scripts/runtime/browser_env_probe.sh; host Node, Chromium, and Playwright are not prerequisites.

Validation

Run commands from the repository root. Use the studio audit before changing studio.html or scripts/studio_main.js; use the full ship gate before opening an MR.
