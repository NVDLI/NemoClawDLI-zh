Course runtime scripts

These modules support the browser course pages. Page HTML imports scripts/_shared.js; that shared module re-exports the page-facing APIs and delegates larger subsystems to smaller siblings.

FileRole
_shared.jsPage chrome, model gateway helpers, service config, exported API surface for lesson pages.
_canvas.jsRunnable code cells and canvas-flow orchestration, including collapsed-code behavior and per-node reset.
_openclaw.jsOpenClaw chat, probe, recovery, logs, and sandbox-policy controls.
_openshell.jsOpenShell command and file-system helpers used by the lab-facing agent runtime.
_chat.jsChat widgets and artifact panels used by interactive lesson sections.
_diagram.js, _viz.js, _figures.jsDiagram grammar, visualization helpers, and page-specific figure builders.
_rag.js, _glossary.jsRetrieval and glossary helpers for local materials and live web-search flows.
_keypanel.jsAPI-key panel and explicit iframe-proxy opt-in controls.
_langchain.jsLightweight LangChain-style teaching helpers for comparison cells.
studio_main.jsAuthoring and inspection studio runtime.
