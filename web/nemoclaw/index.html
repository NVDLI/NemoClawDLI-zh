Securing Agents with OpenShell and NemoClaw

Modern agents are simple underneath: a model wired to tools, memory, and a routing decision, looping until the task is done. This short course builds that system from a single API call, then layers on coordination and retrieval, deep planning, and safe deployment on NVIDIA OpenClaw inside the NemoClaw sandbox. It runs entirely in your browser; there is no lab to provision and nothing to install.

1Drop in your key below. Model calls go to build.nvidia.com through a hosted proxy; a free nvapi- key unlocks every exercise.
2Work the four modules in order. Every cell runs live in the browser, in JavaScript.
3For the agent runtime in Modules 3–4, deploy your own NemoClaw launchable on Brev when a page asks for it.

First: your API key

The key is saved in localStorage on this browser, so it persists across reloads and tabs and carries over to both courses until you clear it with the Change button. It is sent to the hosted proxy, never written into any page.

No key yet? Sign up at build.nvidia.com → Free-tier models cover every exercise.

What you'll build

Each module is one tight idea. The last two are the payoff: instead of mocked panels, you point the browser at a live OpenClaw runtime and watch the same loop you wrote in Module 1 run against the sandbox.

The four modules build in layers. You write the bare loop by hand, add coordination and retrieval on top of it, then drive the real thing under a policy you can tighten. Each page ends in something you run, and the order is a suggestion: act on what a page gives you, and come back for the next layer when a task needs it. This progression is the shape this course chose, and it is one of the shapes a course can take here.

What this course runs on

Every exercise reaches one of three self-contained systems, all from the browser. Nothing else is needed: no DLI lab, no local install.

Models
build.nvidia.com
NVIDIA-hosted Nemotron models, OpenAI-compatible, reached through a hosted Cloudflare proxy. Your nvapi- key is the only thing you bring; the proxy keeps it server-side.
Search
Wikipedia + DuckDuckGo Instant Answer
webSearch returns ranked results from the Wikipedia API; instantAnswer returns a curated card from DuckDuckGo's Instant Answer API for queries it recognizes as an entity. Both are key-less and CORS-open, so they run in the browser with no service to start.
Agent runtime
NemoClaw launchable (Brev)
OpenClaw is the sandboxed agent runtime used in Modules 3 and 4. Deploy your launchable on Brev, paste its gateway URL into the exercise, and the browser drives it directly.
This course is self-contained. It does not depend on a DLI lab or its microservices, and there is no separate assessment to sit. Bring an nvapi- key, work the four modules, and finish on Going Further, which maps where to take these patterns next.
