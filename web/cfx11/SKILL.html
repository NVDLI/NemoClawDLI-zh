web/cfx11

Internal browser candidate for c-fx-11-v1, with digest-bound lesson delivery, executable XBlocks, and learner-owned NVIDIA API access.

Open the course preview, then review source provenance and the fidelity manifest. The imported course is an internal review candidate until its source license is confirmed. Open runtime/ for the browser implementation. The content/ directory holds the original cells and support files; assets/ identifies the local portability asset.

Each imported Python cell remains editable and uses a lesson-specific kernel by default. The Session view can explicitly share one across lessons. Results start hidden, open with a compact visual progress cue, and grow only when evidence arrives. A successful cell with no display value says so explicitly. Results clear before the next run and appear below code by default. The settings menu can move them beside the code and controls editor height, wrapping, line numbers, source restoration, copying, and output clearing. Shift/Ctrl/Command+Enter runs a cell. Ctrl/Command+/ toggles comments. Use ? or ?? for inspection. %magic lists the bounded browser notebook commands.
