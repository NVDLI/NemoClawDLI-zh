Companion-material provenance

Source, terms, and connection level for everything under web/nemoclaw/mats/. The repo is Apache-2.0 (LICENSE.md): course-authored essays and summaries are Apache-2.0, while cached NVIDIA pages and arXiv references keep their source's ownership. Connection levels are a best-effort read of each file's relationship to its source. Image provenance is in assets/SKILL.html.

Connection levels. original: course-authored essay or guide. summary: course-authored notes/card citing a source, no source text reproduced. compilation: course-authored collection of source links/terms. conversion: cached markdown mirror of a source page.

Operations. Agents read the provenance JSON block in the head for the machine manifest; humans read the table below. When you add or change a companion file, update its row (file, type, source, terms, connection) so the provenance stays current.
