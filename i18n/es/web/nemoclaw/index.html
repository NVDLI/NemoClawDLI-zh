Protección de agentes con OpenShell y NemoClaw

Resumen

Agentes modernos están por todas partes y parten de una idea simple: un modelo conectado a herramientas, memoria y una decisión de enrutamiento que continúa en ejecución hasta completar la tarea. El curso construye ese sistema desde cero y conecta cada etapa con los frameworks que utilizan por profesionales de software y por personas sin formación técnica. Avanzarás de una llamada API para coordinación entre agentes, recuperación fundamentada, planificación profunda y implantación segura con NVIDIA OpenClaw y NemoClaw TM.

Objetivos de aprendizaje

Al concluir el curso, sabrás:

  • Construir un ciclo básico de agente e identificar sus componentes centrales.
  • Implementar uso confiable de herramientas y llamadas de función en un sistema de agentes.
  • Diseñar y coordinar sistemas multiagentes con patrones estructurados de enrutamiento.
  • Desarrollar pipelines automatizados de evaluación para medir desempeño y confiabilidad.
  • Usar OpenShell para configurar identidades de agentes y garantizar operaciones seguras en sandbox.
  • Implantar y administrar agentes autónomos mientras crea bibliotecas persistentes de skills.

Cómo informar su clave de API

El navegador guarda la clave en localStorage. Permanece disponible después Recargamientos y otras pestañas hasta que la retire por el botón de cambio. Las solicitudes envían la clave a build.nvidia. con, sin guardarla en ninguna página. Sólo el modo LMS/iframe estático usa el worker de CORS hospedado.

Cómo explorar el material

El orden de los módulos ofrece un camino guiado, pero cada página también funciona de forma independiente. En el recorrido completo, cada módulo aprovecha el anterior: el ciclo ejecutado en navegador se convierte en un workflow de alcance controlado; este workflow pasa a un runtime de agente persistente; y el alcance mayor del runtime justifica el límite impuesto por el sistema operativo. Comience por la tarea relevante para usted. Cada página termina en un artefacto activo y mantiene el código de soporte disponible. Puede cambiar los ejemplos en el navegador, Puede seguir el recorrido por su cuenta o proporcionar este repositorio como contexto a un agente de código.

Stack de agentes
Launchable de NemoClaw en Brev
Este es el stack de agentes en sandbox usado en el taller. OpenClaw proporciona el entorno de ejecución del agente, OpenShell aplica sandbox y NemoClaw organiza los componentes en una implantación de referencia. Por defecto, el ambiente utiliza un launchable de Brev; también puede implantarlo localmente y adaptar el código.
